# أسترو سودان (Astro Sudan)

تطبيق تعليمي يهتم بالتوعية الفلكية والفضائية، بيعرض صورة الفلك اليومية من ناسا (APOD) بواجهة عربية بالكامل.

المطوّر: Elnzer Eshak Haroon — الهيئة العامة للأرصاد الجوي السوداني

## المميزات
- صورة اليوم من ناسا
- أرشيف الصور المحفوظة
- بحث بتاريخ معيّن
- مساهماتي: إضافة محتوى خاص بالمستخدم
- ترجمة اختيارية لمحتوى ناسا للعربي
